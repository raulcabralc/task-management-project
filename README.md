# Task Manager

A small task management application for the Artefact Software Engineer assessment.

This repository is being built in reviewable stages. Stage 1 establishes the Next.js 15, React, TypeScript, Tailwind CSS, tRPC, and Zod tooling. Task management features will be added in later stages.

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

The complete architecture, SSR strategy, storage limitations, and testing instructions will be documented when those features are implemented.
